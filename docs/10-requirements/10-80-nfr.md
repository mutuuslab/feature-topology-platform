# 비기능 요구사항 / Non-Functional Requirements

| ID | 범주 | 요구 | 측정 기준 (목표) |
|---|---|---|---|
| **NFR-1** | 성능 | Impact 그래프 쿼리(3-hop, 단일 Feature)는 대화형 응답 | p95 < 2s, 캐시 시 < 500ms |
| **NFR-2** | 보안 | RBAC verb·domain 스코프, 최소권한; R155/21434 정합 | 모든 변경 액션 verb 검증·감사; TARA 산출물 추적 |
| **NFR-3** | 가용성·복원력 | Registry 조회 고가용; 외부 도구 장애 격리(outbox) | 99.5% 가용; 외부 sync 실패가 코어 트랜잭션 차단 안 함 |
| **NFR-4** | 감사·불변성 | 모든 Lifecycle/배포/Kill 액션 불변 감사 로그 | append-only, actor·time·reason·before/after 보존(≥ N년) |
| **NFR-5** | 확장성 | 엔티티·엣지 규모 증가에 선형 대응 | 수십만 Feature·수백만 Edge까지 설계 여지(대안 B 전환 경로) |
| **NFR-6** | 국제화 | KO-primary + EN 기술용어 병기; ID는 영문 고정 | 모든 라벨 KO/EN 쌍, locale 전환 가능(후속) |
| **NFR-7** | 접근성 | WCAG 2.1 AA | 대비 4.5:1, 키보드 전체 조작, ARIA, 포커스 가시 |

## Gherkin (대표)
```gherkin
Scenario: 권한 없는 사용자의 배포 시도 차단 (NFR-2)
  Given 사용자가 'deploy' verb 권한이 없다
  When Release Readiness에서 Release 버튼을 누르려 한다
  Then 버튼은 비활성(no-permission)이고 "권한 필요: deploy" 툴팁이 보인다
  And 시도는 감사 로그에 기록되지 않으나 UI 접근은 거부된다
```
