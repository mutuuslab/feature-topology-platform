# WF-ROLE-DPO · 데이터 보호 담당 업무 절차서

> 개인정보·위치·주행 데이터의 수집 범위와 보존을 검토한다.

- IAM 역할: 없음(플랫폼 밖 업무)
- IAM 데모 계정: –
- 매핑 근거: 플랫폼 밖 검토 업무

## 1. 내가 하는 일 (수행 R · 책임 A)

### FPW.12-A02 평가 컨텍스트 개인정보 검토 — 수행·책임
- 프로세스: FPW.12 운영 데이터·데이터 보호
- 시작: 정책 작성·변경으로 평가 컨텍스트가 바뀔 때
- 입력: WP-POLICY → 출력: WP-CONTEXT-REVIEW
- 플랫폼: `/integration/openfeature`
1. 정책의 targeting key가 가명 차량 ID인지 확인한다
2. 위치·운전자 식별·연락처·차량 동적 상태가 평가 컨텍스트에 들어가지 않는지 검토한다
3. 금지 속성이 들어오면 평가 전에 거부되는지 시험 결과를 확인한다
- [ ] 금지 속성 거부 시험이 통과했다

### FPW.12-A06 처리 목적·근거 검토 — 수행·책임
- 프로세스: FPW.12 운영 데이터·데이터 보호
- 시작: 새 처리 목적 또는 처리 범위 변경
- 입력: – → 출력: WP-PRIVACY-REVIEW
- 플랫폼: `/admin/data`
1. 수집·이용 목적과 최소 데이터 및 정보주체 범위를 식별한다
2. 동의 또는 적용 가능한 처리 근거의 원본과 보존·접근·이전 제한을 법무와 검토한다
3. 확정된 범위와 미확정 항목을 보안·운영 담당자에게 인계한다
- [ ] 화면 조회나 데모 값으로 동의 획득을 대신하지 않는다
- [ ] 적용 시장과 실제 검토 근거를 식별한다

- FPW.12-A03 중국 데이터 현지 처리·이전 심사 (협의)
- FPW.12-A04 EU 데이터 접근 요청 처리 (협의)

- FPW.12-A07 정보주체 요청 접수 (협의)
- FPW.12-A08 정보주체 독립 처리 (협의)
- FPW.16-A04 백업·복구 점검 (협의)
