## 후속 공통 문구

master 290, dashboard 214, 공통 소형 15모듈 245 = 추가 필수 749개 번역. 현재 원천은 9,077개 중 6,809개 번역, 2,268개 미번역이며 신규 기능으로 분모가 늘 수 있다. 영어 entry 6,905개 함수·값 타입 검사 불일치 0. 후속 기능 통합 시 원장을 원천에서 다시 생성한다.

대시보드 가젯 설명에 남아 있던 구형 `13개 업무 절차` 수를 제거하고 `전체업무흐름`과 전체 절차를 가리키는 문구로 고쳤다. 절차 ID·관계·RACI·원천 산출물 의미는 바꾸지 않았다.

공통 후속에서 기준정보·대시보드·탐색·산출물·관계 설명 6파일 49시험 PASS. 언어·형식·부서 대시보드·개발비 탐색 4파일 19시험 PASS. 새 분류 2경로의 영어 제목 누락을 발견해 보완하고, breadcrumb 그룹과 역할 안내/11개 화면의 역할 라벨을 표시 전용 프록시로 연결했다. canonical 24개 Role·권한 배열·계약 한국어 원본은 불변이며 NextTurn의 원문 라벨 파싱과 정적 감사 원문은 바꾸지 않았다. 추가 관련 3파일 43시험/FE 타입 PASS. 이는 서로 중복되는 회귀 묶음이며 단순 합산한 고유 Case 수가 아니다.

업무 메타데이터는 별도 1,800항목 중 번역 279/원천 영어 365/미번역 1,156이다. 기존 WIP의 FPW.2 part 62개와 출처 fingerprint를 보존했으며, fingerprint는 번역 원천의 일치 기록으로 조직 검토·법규·원천 승인을 뜻하지 않는다.

API가 생성하는 한국어 상세 메시지, 역할·그룹 등 남은 계약 라벨, 아직 채우지 않은 문구와 전문 업무 메타데이터는 별도 후속이다. 화면의 사용자 입력·등록 원문은 영어 모드에서도 그대로 표시한다.
